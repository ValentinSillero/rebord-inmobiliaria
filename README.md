# Esteban Rebord Negocios Inmobiliarios

Sitio web inmobiliario desarrollado con Next.js.

## Requisitos

- Node.js compatible con Next.js 15 (`^18.18.0`, `^19.8.0` o `>=20.0.0`).
- npm.

## Instalación

```bash
npm install
```

## Ejecutar desarrollo

```bash
npm run dev
```

La aplicación queda disponible por defecto en `http://localhost:3000`.

## Build

```bash
npm run build
```

Para ejecutar el build de producción:

```bash
npm run start
```

## Variables de entorno

Copiar `.env.example` como `.env.local` y completar únicamente las variables necesarias para el entorno local. No se deben versionar credenciales ni secretos.

Las integraciones de base de datos, almacenamiento de imágenes y acceso administrativo se implementarán en próximos sprints; actualmente no están activas.
